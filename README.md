## 📌 Descripción General
Este repositorio contiene el desarrollo y las resoluciones de las actividades y ensayos prácticos correspondientes a la materia **Sistemas de Computación**. Todos los ejercicios requeridos han sido **completados de forma efectiva**.

---

## 📁 Estructura del Repositorio

* **`Ej1-Coremark/`**: Pruebas de rendimiento de procesamiento mediante el benchmark *CoreMark*.
* **`Ej3-Código-ESP32/Test_int_float_double`**: Código y pruebas comparativas sobre microcontrolador ESP32 analizando el desempeño con distintos tipos de datos (`int`, `float`, `double`).
* **`Ej4-Gprof/`**: Análisis de perfilado de código (profiling) de programas utilizando la herramienta `gprof`.
* **`Informe/`**: Informe sobre las actividades realizadas y resultados.
